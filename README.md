# AOH2-VerySmallMod: Next-Generation Grand Strategy Overhaul

Мод нового покоління для гри **Age of History 2: Definitive Edition**, який перетворює класичну гру на глибоку, збалансовану та комфортну глобальну стратегію.

---

## 🌟 Ключові механіки та нововведення

### 1. 🕊️ AI Anti-Border-Gore & Реалістичні мирні договори
В оригінальній AoH2 мирні договори штучного інтелекту призводили до потворного "бордер-гору" (анклави, розірвані провінції по всьому світу, дірки посеред країн). Мод повністю перебудовує логіку вибору провінцій ШІ:
- **Сувора неперервність кордонів**: ШІ більше не захоплює відірвані анклави через усю карту. Провінції відбираються лише за наявності безпосереднього сухопутного кордону або прямого морського сполучення через одну акваторію.
- **Виправлення цілочисельного ділення в коефіцієнті зв'язності**: виправлено критичний баг оригінального рушія, через який оцінка географічної компактності обнулялася.
- **Бонус за закриття кишень і заток**: ШІ отримує вагомий пріоритет (до +25 очок) за ліквідацію анклавів та закриття провінцій, які вже оточені з 3 або 4 боків.
- **Ліквідація 1-провінційних дірок**: усунено ситуації, коли всередині монолітної імперії залишалася ізольована провінція переможеного ворога.

---

### 2. 👑 Мирне приєднання васалів (Peaceful Vassal Annexation)
Додано повноцінну дипломатичну механіку мирної інтеграції васалів без необхідності надсилати агресивні ультиматуми та руйнувати стабільність:
- **Вимоги для приєднання**:
  - Стосунки між сюзереном та васалом $\ge +50.0$.
  - Термін васалітету не менше **5 років** (або 50 ходів).
  - Бажання свободи васала $< 50\%$.
  - Обидві держави повинні перебувати в стані повного миру.
- **Повна інтеграція армії**: війська васала не зникають, а переходять під прапори сюзерена та об'єднуються з гарнізонами.
- **Захист від зависань (Bulletproof State Transition)**: повністю перероблено процедуру передачі володінь; усунено фатальні помилки виходу за межі списку при зміні столиці та активних меню.
- **Баланс загрози (Агресивна експансія)**: мирне приєднання великого васала не проходить непоміченим — сусідні незалежні держави відчувають зростання загрози, що створює природний дипломатичний баланс.

### 3. ⚙️ Комплексний Авто-розвиток провінцій ("Smart ROI" & "Auto-Core")
Потужний модуль автоматизації внутрішньої політики з доступом через меню паузи (ESC) або дипломатію:
- **Smart ROI (Розумний вибір інвестицій)**:
  $$\text{ROI} = \frac{\text{Населення}}{\text{Економіка} + 50} \times (1.0 + \text{GrowthRate})$$
  Кошти вкладаються насамперед у ті провінції, які дають максимальну фінансову віддачу на кожну витрачену золоту монету.
- **Авто-коринг (Національна інтеграція)**: провінції, що досягли стабільності $\ge 95\%$, автоматично отримують статус корінних національних земель без виснажливого очікування 50 ходів.
- **Авто-будівництво інфраструктури**: автоматичне зведення майстерень (збільшення доходу) та бібліотек (прискорення технологічного прогресу) відповідно до доступного бюджету.
- **Демобілізація тилових гарнізонів в 1 клік**: автоматичний розпуск надлишкових армій у глибоких безпечних провінціях (залишається гарнізон у 500 воїнів), що заощаджує тисячі золотих на утриманні щоходу.
- **Черга пріоритетів та захисні резерви**: налаштування черги (Асиміляція $\to$ Ярмарки $\to$ Економіка $\to$ Дослідження) та збереження недоторканного запасу скарбниці й очок пересування.

### 4. 🎨 Адаптивний UI та вивірені хітбокси (`DevButton`)
- **Повна ліквідація налізань та зміщень кліків**: створено клас `DevButton` з точним розрахунком координат 1:1, що усунуло розширені невидимі зони колізій оригінального `Button_Classic`.
- **Авто-масштабування під будь-які монітори**: макет динамічно підлаштовується під роздільну здатність екрана (962x725, 1280x720, 1366x768, 1920x1080) та перевіряється вбудованим тестом `MenuLayoutVerifier`.
- **Збереження стану меню**: при кліках по перемикачах чи пресетах діалогове вікно не закривається, забезпечуючи плавний робочий процес.

## 🛠️ Збірка та встановлення

### Швидкий запуск (Windows):
Запустіть файл `build.bat` або виконайте в PowerShell:
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```
Скрипт автоматично:
1. Виявить встановлений JDK (Adoptium / Oracle 8-17).
2. Створить резервну копію оригінального `game.jar` (якщо ще немає).
3. Скомпілює всі модулі під Java 8 для сумісності з рушієм.
4. Впровадить скомпільовані класи в гру та синхронізує файли модифікації.

### Повернення до оригінальної гри (Uninstall):
Запустіть `restore.bat` (або `restore.ps1`), і оригінальний `game.jar` буде негайно відновлено.
