# AOH2-VerySmallMod

Мод для гри **Age of History 2: Definitive Edition**, який додає можливість перемикатися на будь-яку іншу країну прямо під час поточної партії з меню налаштувань (ESC).

## 🎮 Основні можливості

1. **Кнопка "Змінити країну" в меню паузи (ESC)**:
   - Додано нову кнопку в головне внутрішньоігрове меню.
   - Відкриває окреме вікно вибору цивілізації.

2. **Меню вибору цивілізації (`Menu_SwitchCountry`)**:
   - **Швидкий вибір обраної провінції**: Якщо перед відкриттям меню на карті була виділена провінція іншої держави, вгорі з'являється кнопка миттєвого переходу на цю державу (`⚡ Обрана провінція: [Країна]`).
   - **Повний список усіх живих держав**: Відсортований за розміром та статусом (поточна держава позначена зірочкою `★ [ВИ ГРАЄТЕ ЗАРАЗ]`).
   - Відображення назви, прапора та кількості підконтрольних провінцій.

3. **Безпечне та повне оновлення стану гри**:
   - Автоматично перераховує Туман Війни (Fog of War) для нового гравця (включно з союзниками та васалами).
   - Оновлює прапор у верхньому кутку та показники скарбниці, очок пересування, дипломатії і рангу.
   - Оновлює шейдери карти та центрує камеру на столицю нової держави.
   - Не пошкоджує збереження та дозволяє грати далі в звичайному режимі.

---

## 🛠️ Збірка та встановлення

У репозиторії знаходяться лише вихідні коди моду. Файли самої гри сюди **НЕ** входять.

### Вимоги:
* Встановлений JDK (Java 8 або новіша версія, наприклад OpenJDK 17/21).

### Встановлення моду:
```bash
cd "mods/AOH2-VerySmallMod"
./build.sh
```
Скрипт автоматично:
1. Створить резервну копію `game.jar.original` (якщо її ще немає).
2. Скомпілює класи під Java 8 сумісність.
3. Впровадить скомпільований мод у `game.jar`.

### Відкат до чистої гри (Vanilla):
```bash
./restore.sh
```
Це поверне оригінальний `game.jar` без жодних змін.
