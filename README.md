# AOH2-VerySmallMod

Мод для гри **Age of History 2: Definitive Edition**, який розширює функціонал управління державою та дипломатією.

## 🎮 Основні можливості

1. **Кнопка "Змінити країну" в меню паузи (ESC)**:
   - Відкриває окреме вікно вибору цивілізації.
   - Швидкий вибір обраної провінції в 1 клік.
   - Повний пошук цивілізацій за назвою та тегом.
   - Безпечне та повне оновлення туману війни (Fog of War), інтерфейсу та скарбниці.

2. **Меню автоматичного розвитку провінцій ("Авто-розвиток провінцій" в ESC)**:
   - **Авто-економіка**: автоматично вкладає золото та очки пересування щоходу в розвиток економіки провінцій.
   - **Гнучке регулювання цільової економіки**: наприклад, при виборі 100% економіка прокачується до 100% від населення (100к нас. -> 100к екон.), при 120% — до 120к, тощо.
   - Швидкі кнопки коригування (-50%, -10%, +10%, +50%) та готові пресети (80%, 100%, 120%, 150%, 200%).
   - **Авто-дослідження**: автоматично розвиває рівень досліджень/розвитку у провінціях до максимального доступного технологічного рівня держави.
   - Можливість негайного ручного запуску інвестицій кнопкою "⚡ Інвестувати зараз".

3. **Баланс васалітету (x3.5)**:
   - Поріг співвідношення бюджету для прийняття васалізації знижено з x5.0 до **x3.5**.
   - Синхронізація ідеології та альянсів васалів із сюзереном.
   - Меню мирної анексії васалів.

4. **Виправлення асиміляції / стабільності під час хвороб**:
   - Під час епідемій та хвороб стабільність/асиміляція провінцій більше не просідає штучно на 20% (до 80%) через штраф хвороби (`STABILITY_DISEASE = 0.0`).

## 🛠️ Збірка та встановлення

### Для Windows:
Просто запустіть `build.bat` (або `build.ps1` у PowerShell).
Скрипт автоматично:
1. Знайде встановлену гру та JDK (Java 8+).
2. Створить резервну копію `game.jar.original` (якщо ще немає).
3. Скомпілює вихідний код у Java 8 (UTF-8).
4. Впровадить скомпільовані класи в `game.jar`.
5. Синхронізує конфігураційні файли в папку `mods/` гри.

### Для Linux / Git Bash:
```bash
./build.sh
```

### Відкат до чистої гри (Vanilla):
Запустіть `restore.bat` (або `restore.ps1` / `./restore.sh`).
